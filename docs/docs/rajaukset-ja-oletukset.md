# Rajaukset ja oletukset

### 1.4 Rajaukset ja oletukset
Projektin laajuus rajataan yhteen mikropalveluun, Tiellä liikkujan mikropalveluun. MVP-versio tukee vain autoilureittejä ja toimii yksinkertaisena web-sovelluksena ilman käyttäjätunnistusta. Oletuksena on, että käyttäjällä on toimiva internet-yhteys, sijaintilupa sekä pääsy tarvittaviin avoimiin rajapintoihin.
