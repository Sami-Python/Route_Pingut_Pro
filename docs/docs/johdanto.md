# Johdanto

1.1 Projektin tausta
Kurssin tavoitteena on kehittää mikropalveluarkkitehtuuriin perustuva sovellus, joka hyödyntää nykyaikaisia ohjelmistoteknologioita ja tukee opiskelijan tai korkeakouluyhteisön arkea konkreettisella tavalla.Projektin päämääränä on toteuttaa toimiva, skaalautuva ja dokumentoitu mikropalvelu, joka kommunikoi muiden palveluiden kanssa määriteltyjen rajapintojen kautta. Jokaisella mikropalvelulla on selkeä vastuualue ja rajapinta (API), jonka avulla se tarjoaa tietoa tai toiminnallisuutta muille järjestelmän osille. Rajapinnat määritellään ja dokumentoidaan Swagger/OpenAPI-standardin mukaisesti. Koodi testataan automatisoiduilla yksikkötesteillä ja analysoidaan staattisen koodianalyysin avulla, jotta saavutetaan laadukas ja ylläpidettävä kokonaisuus.
